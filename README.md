# Projects-Road-map-js

Repositório com os projetos que desenvolvo seguindo o roadmap de JavaScript do [roadmap.sh](https://roadmap.sh).

## 📚 Projetos

| Projeto | Descrição | Status |

[Greeting Builder](https://roadmap.sh/projects/js-greeting-builder) | Projeto em JavaScript que combina funções pequenas e reutilizáveis para formatar nomes e escolher a saudação correta (manhã, tarde ou noite), retornando mensagens como “Good morning, Ava Stone”. | ✅ Concluído 

[Temperature Converter](https://roadmap.sh/projects/js-temperature-converter) | Projeto em JavaScript com funções para converter temperaturas de Celsius para Fahrenheit e vice-versa, além de uma função auxiliar que formata o resultado com a unidade (ex.: “77 F” e “20 C”). | ✅ Concluído

[Number Check](https://roadmap.sh/projects/js-number-checker) | Projeto em JavaScript com pequenas funções que classificam um número inteiro (positivo, negativo, zero, par ou ímpar) e uma função que reúne todas as verificações em um único objeto, como {positive: true, negative: false, zero: false, even: false, odd: true} para o número 5. | ✅ Concluído
